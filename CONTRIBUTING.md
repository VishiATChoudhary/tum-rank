# Contributing

TUM Rank is run by students. Anyone can help.

- **Something wrong or missing?** [Open an issue](https://github.com/VishiATChoudhary/tum-rank/issues/new/choose).
- **Want to fix it yourself?** Fork, make a branch, open a pull request. Keep PRs small and say what you changed and why.
- **Missing a course or degree?** Use "Suggest course" / "Request another degree" on the site. A moderator approves it.

People who land a few good PRs get added as collaborators and can help moderate.

## Ground rules

- No tracking, no ads, no accounts. Ratings stay anonymous.
- User text is always rendered with `textContent`, never `innerHTML`.
- Every new API input needs server-side validation in `api/index.py`.
- Run the site locally (see README) and click through your change before opening the PR.
